## 中文

基于 `v1.1.1..v1.1.2` 的提交整理（含版本提交）。桌面仍是 **app:// + 双 IPC 运行时**。

本版主要落地三件事：会话可以**归档**而不是删除；中断到一半的工具调用会在下次发送前被**自动补齐错误结果**；模型设置改成**单列卡片钻入**式界面。另外修了一个常见的自定义模型 400 问题，并做了两处安全加固。

---

### 新增

- **会话归档**
  - 侧边栏会话菜单从「删除」改为「归档」：软归档，文件留在磁盘
  - 新增 **设置 → 已归档** 面板：列出已归档会话（标题 / 消息数 / 路径 / 归档时间），可**恢复**或**永久删除**（两步确认）
  - 归档 / 恢复只重写会话头两字段（原子 tmp+rename），不碰正文
- **会话工具修复（session-tool-repair）**
  - 上一版只有设计文档，这版实现：会话在工具调用中途被中断后，下次打开 / 发送前会自动补一条 `Tool did not finish (session interrupted).` 的错误 toolResult（磁盘 + 内存双写，幂等）
  - 之前这种会话下次发送会因消息序列不完整被 provider 拒绝，现在可以继续对话
- **模型设置：单列卡片钻入**
  - 双栏弹窗 + 整页保存按钮 → 单列设置卡片 + 每行钻入详情（返回条）
  - 每次编辑**即时保存**（按 provider PATCH），失败自动回滚并提示；去掉保存按钮 / 未保存确认弹窗
- **模型/供应商保存时自动规范化**
  - 删除遗留的每模型 `cost` / `thinkingMapLocked` 字段
  - 清理旧版死字段 `developerRole` / `useDeveloperRole`
- **`enabledModels` 歧义报错**：一个裸 id 匹配多个 provider 时给出明确错误，不再模糊解析到错误的模型；支持 `:thinkingLevel` 后缀精确定位
- **工具执行进度**：流式输出时，运行中的工具在对话里显示最新一行进度文本（单一提取归属）
- **LINUX DO 社区认可**：README / 产品页加入社区链接与印章（开源推广）

---

### 修复

- **自定义 OpenAI 兼容 provider 发送 400**：pi-ai 在 `reasoning` + `compat.supportsDeveloperRole` 都开启时会发 `role: "developer"`，而 URL 自动探测对未知网关默认开启——火山方舟 / Azure / vLLM 等网关直接 400。现在保存时对非 OpenAI 官方 / OpenRouter 的兼容 provider 显式写入 `supportsDeveloperRole: false`（模型级显式设置仍优先）
- **主题构造参数类型修复**（pi 0.84.2 新增 `searchMatchText` 后的编译问题，纯类型修复）
- **打包 OAuth 依赖去重**：bundled OAuth 导入改指向 pi-coding-agent 嵌套 node_modules，esbuild 只发一份 `load.js`
- **项目 shell 环境隔离**：agent bash 工具启动的项目命令不再继承宿主 `PORT` / `NODE_ENV` / `NEXT_*`（端口来自上游 issue #487，防宿主运行时配置泄漏进用户项目）
- **Skill 文件访问符号链接逃逸**：读 / 改 `SKILL.md` 前做 realpath 校验，词法上在允许根内但真实路径逃逸（symlink）的一律 403
- **Windows 路径大小写 / 分隔符归并**：会话 / worktree 按服务器计算的 `projectKey` 归组，同一项目不同写法折叠成一个侧边栏项目（不再客户端推导 key）

---

### 内部调整

- `GET /api/sessions` 不再返回 `runningSessionIds`（运行态只由 heavy 的 `/api/agent/running` 提供）
- 子代理目录按「最新父回合」限域，只展示本回合创建的子代理（运行中的始终显示）
- 文件查看器元请求加竞态守卫
- 会话工具修复被归类为 **prepare-for-convert**：恢复路径仍为 5 条，无新增、无双轨
- models.json 读写统一收口到 `lib/models-config-json.ts`；新增按 provider 的 PATCH/DELETE 端点

## English

Prepared from commits in `v1.1.1..v1.1.2` (plus the version bump). Desktop remains **app:// + dual IPC runtimes**.

This release: sessions can be **archived** instead of deleted; tool calls interrupted mid-batch get **auto-repaired** before the next send; the models settings became a **single-column card drill-in**. Also fixed the common custom-provider 400 and hardened two security edges.

---

### Added

- **Session archiving**
  - Sidebar session menu changed Delete → Archive (soft archive; files stay on disk)
  - New **Settings → Archived** panel: title / message count / cwd / archived date, with Restore and Delete-forever (inline two-step confirm)
  - Archive/restore rewrites only the session-header fields (atomic tmp+rename)
- **Session tool repair** (spec-only in 1.1.1, now implemented)
  - A session interrupted mid-tool-call gets a synthetic error `toolResult` ("Tool did not finish (session interrupted).") appended on open and before the next prompt (disk + in-memory, idempotent)
  - Previously such sessions could be rejected by the provider on the next send; now they resume
- **Models settings: single-column card drill-in**
  - Dual-pane modal + whole-file Save → card list with per-row drill-in (back strip)
  - Edits save **instantly** per-provider (PATCH), rollback + banner on failure; Save button / unsaved-changes dialog removed
- **Model/provider config normalization on save**
  - Drops legacy per-model `cost` / `thinkingMapLocked`
  - Strips dead `developerRole` / `useDeveloperRole` keys
- **Ambiguous `enabledModels` error** — a bare id matching multiple providers now fails loudly instead of fuzzy-resolving to the wrong model; `:thinkingLevel` suffix resolution added
- **Tool execution progress** — running tools show the latest progress line in the transcript (single extraction owner)
- **LINUX DO acknowledgment** — README / product page link + seal

---

### Fixed

- **Custom OpenAI-compatible providers 400 on prompt**: pi-ai sends `role: "developer"` when `reasoning` + `compat.supportsDeveloperRole` are both truthy, and URL auto-detection defaults that flag on for unknown hosts — Volcano Ark / Azure / vLLM and friends hard-400 it. On save we stamp `supportsDeveloperRole: false` for non-OpenAI/OpenRouter compat providers (explicit model-level keys still win)
- **Theme constructor cast** — pi 0.84.2 added `searchMatchText`; direct casts stopped compiling (pure type fix)
- **Bundled OAuth dedupe** — imports resolve via pi-coding-agent's nested node_modules so esbuild emits a single `load.js`
- **Project shell env isolation** — agent bash no longer leaks host `PORT` / `NODE_ENV` / `NEXT_*` into project commands (upstream issue #487)
- **Skill symlink escape** — realpath check before reading/patching `SKILL.md`; lexical-in-root-but-realpath-out paths now 403
- **Windows project grouping** — sessions/worktrees group by server-computed `projectKey` (casing/separator folding); client-side key derivation removed

---

### Internal

- `GET /api/sessions` no longer returns `runningSessionIds` (running state only from heavy `/api/agent/running`)
- Subagent catalog scoped to the latest parent turn (running ones always shown)
- FileViewer meta-request race guard
- Session tool repair classified as **prepare-for-convert** — still 5 run-lifecycle recovery paths, no dual-path
- models.json I/O owned by `lib/models-config-json.ts`; new per-provider PATCH/DELETE endpoint

---
